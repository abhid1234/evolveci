LinkedIn hook

Your pull request passes every test. Did it quietly make the next change harder?

That question nerd-sniped me, so over a few weekends I built EvolveCI—an experiment in counterfactual CI.

A maintainer defines a plausible follow-up task and deterministic verifier. EvolveCI runs the same task against base and head, then compares the patches the agent had to make.

The demo: same current behavior, but the next role takes one changed file on base and four on the coupled head. Green today; more expensive tomorrow.

It is rough and early. I would love people to poke holes in the scenario model.

EvolveCI runs a repository-owned future-change probe against base and head in detached worktrees, then compares success, patch evidence, duration, dependencies, variability, and failures. The demo is deterministic and illustrative; the alpha is explicit about its limits.
